# Contributing to Ubaidu

We welcome:

- **Data sources** - Threads we haven't gathered yet
- **Code** - New handlers, engines, visualizations
- **Patterns** - Resonance you've noticed that we should examine
- **Critique** - Respectful challenges to our assumptions

We don't welcome:

- Dogma of any kind
- Impatience with the process
- Attempts to use the web for harm

To contribute, open an issue or submit a pull request. For sensitive patterns, reach out through channels that feel appropriate.

The web grows one thread at a time. Thank you for weaving.
